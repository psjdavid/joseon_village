# 朝鮮 마을 (joseon_village)

고을 수령이 되어 작은 마을을 번성한 고을로 키우는 **조선 시대 마을 건설 게임**입니다.
심시티·시티즈 스카이라인 같은 도시 건설 게임을 조선 마을 컨셉으로 만들었어요.

- 설치 없이 `index.html` 하나를 브라우저로 열면 바로 실행됩니다.
- 비스듬히 내려다보는 아이소메트릭 시점, 그림 파일 없이 캔버스로 직접 그렸습니다.
- 진행 상황은 브라우저에 자동 저장됩니다.

## 게임 방법

| 건물 | 하는 일 |
|---|---|
| 관아 | 세금을 걷고 주변 민심을 높임 (처음부터 있음) |
| 길 | 집과 건물을 이어줌 |
| 초가집 | 백성 5명 거주. 길 옆에 지어야 함 |
| 논 | 쌀 생산. 강에서 3칸 이내면 수확이 좋고, 가을에 가장 많이 거둠 |
| 벌목장 | 주변 2칸 숲에서 목재 생산 |
| 우물 | 근처 집 민심 상승, 역병 피해 감소 |
| 장터 | 근처 집 민심·세수 상승, 장사 수입 |
| 서당 | 근처 집 민심 상승. 백성 30명부터 |
| 기와집 | 백성 14명 거주. 서당 + 백성 60명부터 |
| 성곽 | 20칸 이상이면 도적을 막아냄 |

- **자원**: 엽전, 쌀, 목재, 백성, 민심
- **계절**: 봄·여름·가을·겨울이 돌며, 겨울에는 논이 쉬고 쌀을 더 먹습니다.
- **사건**: 가뭄, 풍년, 역병, 도적 떼
- **세율**: 높이면 엽전이 늘지만 민심이 떨어집니다.

## 조작

- 아래 도구에서 건물을 고르고 땅을 클릭 (길·논·성곽·철거는 드래그로 여러 칸)
- 빈 곳 드래그 / 방향키·WASD: 화면 이동, 휠·두 손가락: 확대·축소
- 오른쪽 클릭 / Esc: 도구 선택 해제, Space: 일시정지
